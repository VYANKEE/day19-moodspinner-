---

### ✨ Key Features
- **🎭 Mood Detection:** UI theme & colors change instantly based on your text (e.g., "Sad" → Blue, "Angry" → Red).
- **🎡 Physics Spinner:** Custom wheel animation with realistic friction.
- **💎 Glassmorphism UI:** Premium dark mode aesthetic with neon glows.
- **⚡ 100% Logic:** No AI, just pure React state & CSS variables.

### 🛠️ Tech Stack
- **Framework:** React + Vite
- **Styling:** Pure CSS (Animations, Variables)
- **Icons:** Lucide React
- **Routing:** React Router DOM

### 🚀 How to Run Locally
```bash
git clone [https://github.com/YOUR_USERNAME/mood-spinner.git](https://github.com/YOUR_USERNAME/mood-spinner.git)
cd mood-spinner
npm install
npm run dev)**
